Audio Brick firmware installer

Installs the open firmware for the Sonocotta Esparagus Audio Brick (ESP32 version) from your browser. Use Chrome or Edge on a computer; the Brick must be connected with its USB-C cable.

If it does not connect

On at least one board the automatic reset into download mode does not work. Then: press Install and pick the port, hold the BOOT button (the one farther from the board edge), tap EN (the one nearer the edge), keep holding BOOT until the installer reports it is connected. When the install is finished, tap EN once to start the new firmware.

What this does

  • Writes the bootloader, the partition table and the firmware. Settings (web password, Bluetooth pairings, volume) and stored clips are kept, unless the partition table changed between versions (then the clips are erased and have to be uploaded again).
  • After that, updates go over the network: the web page of the Brick has a firmware upload, and audiobrick-ota.bin from the release page is the file to upload.
  • The first start prints the web password on the serial console (115200 baud).
