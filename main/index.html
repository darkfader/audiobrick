Idle
Same safe steps as the tone slider: each step up is limited to 2 dB and Page Up/Down, Home and End are disabled.

Network stream

The board listens on TCP port 4010. From a PC run python tools/stream.py 192.168.2.40 song.mp3, or add --device "CABLE Output (VB-Audio Virtual Cable)" to send system audio. The password is asked on the command line.

Clip manager

Drop .mp3 or .wav files here, or
MP3 (any bit rate) and 16-bit WAV play; other sample rates are converted. Names: letters, digits, dot, dash, underscore. Mono 96 kbps MP3 is about 12 KB per second, so the 12 MB holds roughly 15 minutes. Do not upload or delete while something is playing (flash writes can glitch the sound).

Log in

Stays logged in on this browser for 30 days. The page uses plain HTTP, so use it on your own network only.

Test tone

Safe sliders: each step up is limited to 2 dB, so clicking the track or dragging fast cannot jump to a loud level. Page Up/Down, Home and End are disabled. Press Esc to stop. The tone also stops by itself within 15 seconds if this page is closed or loses the connection.

Speaker EQ

The same filters run on both channels, for tones, streams and clips. The preamp is automatic: it cancels the largest boost, so the EQ never raises the level above the loudness cap. Limits: 20–20000 Hz, Q 0.2–10, gain −15 to +6 dB. Untick "EQ enabled" and press Apply to compare with the bare sound.
